# Quality and Scope Statement

专题首页：[Big Tech Architecture Atlas](README.md)

## What This Project Is

This project is a practical learning atlas for software architecture.

It helps engineers:

- recognize common architecture patterns,
- separate architecture core from dependencies,
- read diagrams and sequence flows,
- understand standard I/O contracts,
- find minimal GitHub demos,
- review real codebases from a higher level,
- and make better architecture decisions.

## What This Project Is Not

This project is not:

- a universal architecture rulebook,
- a replacement for production architecture review,
- legal, financial, security, or compliance advice,
- a benchmark of all technologies mentioned,
- or a claim that big-tech practices should be copied blindly.

## Quality Principles

- Architecture should solve real pain, not signal sophistication.
- Start simple and add complexity only when needed.
- Boundaries matter more than tool names.
- Dependencies should not leak into business core.
- Diagrams should explain flow, not decorate documents.
- Demos should be small enough to study.
- Every architecture has trade-offs.

## Link and Demo Policy

External GitHub demo links are selected for learning value.

A demo is preferred when it is:

- public,
- easy to inspect,
- reasonably small,
- actively maintained or widely known,
- and clearly related to the architecture pattern.

External links may change over time. If a link is broken or a better demo exists, open an issue using the demo request template.

## AI and Security Notes

AI architecture content, including RAG, LLMOps, and Agentic Architecture, should be treated as engineering learning material.

For production systems, always review:

- data privacy,
- access control,
- audit logging,
- model evaluation,
- prompt injection risk,
- tool permission boundaries,
- and regulatory requirements.

Security architecture content, including Zero Trust, IAM, Policy as Code, and Audit Architecture, is educational and should be validated by qualified security reviewers before production use.
